# 🍎 POM Blast

A modern cinematic landing page for a premium pomegranate juice brand built using React, Vite, and GSAP animations.

## 🚀 Live Demo

Add your Netlify URL here:

```text
https://your-site-name.netlify.app
```

## ✨ Features

* Cinematic hero section
* Animated pomegranate showcase
* GSAP powered transitions
* Responsive design
* Modern UI/UX
* Video background effects
* Optimized for deployment

## 🛠️ Tech Stack

* React
* Vite
* JavaScript
* CSS3
* GSAP
* Netlify

vite-project/

## ⚙️ Installation

```bash
git clone https://github.com/sravanakkaladevi/pom-blast.git

cd pom-blast/vite-project

npm install

npm run dev
```

## 📦 Build

```bash
npm run build
```
